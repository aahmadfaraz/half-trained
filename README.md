# Half-Trained

Code behind the Half-Trained YouTube channel. Watch AI learn the hard way.

YouTube [@halftrained](https://www.youtube.com/@halftrained) · X [@half_trained](https://x.com/half_trained)

Every AI in our videos is trained for real with the code here. Each experiment folder has the
environment, training and evaluation scripts, settings, seeds and results.

## Experiments
| # | Video | Folder |
|---|---|---|
| 01 | [AI Learns to Land a Rocket. Then I Break One Engine.](https://youtu.be/_D4dPklPbP8) | `experiments/v01-rocket` |

## Setup
Python 3.12:
```
pip install -r requirements.txt
```
Each experiment folder has its own README with results and the exact commands to reproduce them.
